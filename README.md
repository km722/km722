Some of my projects:
- [data-agent](https://github.com/km722/data-agent): an autonomous data-cleaning agent built on the raw Anthropic API, no agent frameworks. It inspects a messy CSV, writes and runs its own cleaning code, fixes its own errors, and saves a cleaned file plus a report. Every output value has to come from the source data or a tool result, never the model's memory. Scored by a 10-check harness I wrote after hand-grading proved unreliable. My best hand-scored run, a 97, dropped to 0 once the script caught four invalid dates and a $408M value cleaned down to $4. Fixing those took the next run to 92.
- [energy-signal-llm](https://github.com/km722/energy-signal-llm): an LLM pipeline that labels a year of Guardian headlines with weather events and regions (Claude Haiku, 90% event accuracy against 140 hand-labelled headlines), then tests whether those events move day-ahead electricity prices in five European markets. They don't, and the placebo control shows why that's the right answer.
- [hypertension-detection](https://github.com/km722/hypertension-detection): my dissertation. Ensemble models that flag undiagnosed hypertension from routine blood tests (NHANES, n=10,739, AUC 0.823 under temporal validation), with SHAP interpretability and a small Streamlit demo.
- [gdp-forecasting-deep-learning](https://github.com/km722/gdp-forecasting-deep-learning): LSTM vs CNN-LSTM vs Transformer for 5-year GDP per capita forecasting across 219 countries.
- [insurance-cross-sell-ml](https://github.com/km722/insurance-cross-sell-ml): dealing with 7:1 class imbalance. kNN written from scratch, SMOTE, class-weighted trees. Recall went from 5% to 54%.
- [rl-tictactoe-agents](https://github.com/km722/rl-tictactoe-agents): Q-learning, Value Iteration and Policy Iteration in Java, no RL libraries.
- [csharp-web-browser](https://github.com/km722/csharp-web-browser): a desktop web browser in C# and Windows Forms. Handles HTTP errors, timeouts and DNS failures, and keeps each user's bookmarks and history in SQLite.
- [r-statistical-modelling](https://github.com/km722/r-statistical-modelling): ARIMA forecasting and customer segmentation in R.
